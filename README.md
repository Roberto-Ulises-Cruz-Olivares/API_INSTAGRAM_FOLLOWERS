# API_INSTAGRAM_FOLLOWERS ------> DEMO VERSION 1
Una API simple y eficiente que extrae todos los seguidores de un usuario específico en Instagram.

Requisitos --> Necesitar tener los 3 tokens de inicio de sesion de tu cuenta activa: SESSIONID, CSRFTOKEN Y DS_USER_ID


Una vez extraidas las credenciales poner de la siguiente forma en la terminal: 

$env:IG_SESSIONID="TOKEN_AQUI"
$env:IG_CSRFTOKEN="TOKEN_AQUI"
$env:IG_DS_USER_ID="TOKEN_AQUI"

NOTA: EL USER DEBE TENER LA CUENTA PUBLICA O SEGUIRTE PARA PODER EXTRAER LOS FLLOWERS
      MUCHAS PETICIONES AL SERVIDOR DE INSTAGRAM BANEARAN TU ID DURANTE 1 SEMANA APROXIMADAMENTE
